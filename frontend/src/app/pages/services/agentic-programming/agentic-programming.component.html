03 / Vorgehen agentic-programming

So gehen wir vor

Die Agenten schreiben den Code. Architektur, Prüfung und Verantwortung bleiben bei uns.

01

Abläufe statt Lastenheft

Wir klären an echten Beispielen aus Ihrem Alltag, was die Software können muss — nicht an einem 80-seitigen Lastenheft. Soll sie bestehende Software ablösen, schauen wir zuerst, welche Funktionen davon wirklich genutzt werden.

02

Architektur und Leitplanken

Bevor ein Agent eine Zeile schreibt, legen wir Architektur, Technologien und Sicherheitsvorgaben fest. Standard-Technologien, die Ihr Team oder jeder andere Dienstleister weiterpflegen kann.

03

Entwicklung mit Agenten

KI-Agenten implementieren in kurzen Iterationen. Jede Änderung ist ein nachvollziehbarer Commit in Ihrem Repository, und Sie sehen den Fortschritt an lauffähiger Software, nicht an Statusberichten.

04

Tests, Review, Security

Kein Code geht ungeprüft live: automatisierte Tests, Review durch uns, SAST, Dependency- und Secret-Scanning in der Pipeline. Derselbe Standard, den wir aus DevSecOps-Projekten unter BaFin-Aufsicht kennen.

05

Betrieb

Auf Ihrer Infrastruktur oder in Ihrer Cloud, als Container — auf Wunsch auf einem Kubernetes-Cluster, den wir mit Ihnen aufbauen.

06

Übergabe

Quellcode, Dokumentation und Pipeline liegen in Ihrem Repository. Ihr Team kann selbst weiterentwickeln — mit oder ohne Agenten, mit oder ohne uns.

05 / Fragen agentic-programming

Häufige Fragen

„Ist Code, den eine KI schreibt, sicher?"

So sicher wie der Prozess, der ihn prüft. Bei uns läuft jede Änderung durch automatisierte Tests, Security-Scans und ein Review durch einen erfahrenen Engineer. Verantwortlich für das Ergebnis sind wir, nicht das Sprachmodell.

„Was heißt ‚Nachbau' von Standardsoftware?"

Wir entwickeln eine eigene Lösung, die die Aufgaben Ihrer bisherigen Software übernimmt — zugeschnitten auf das, was Sie tatsächlich nutzen. Fremder Quellcode, Markennamen oder geschützte Oberflächen werden nicht übernommen. Die neue Software ist von Grund auf Ihre.

„Wem gehört der Code?"

Ihnen. Quellcode, Dokumentation und Pipeline liegen in Ihrem Repository, auf Standard-Technologien, die jeder qualifizierte Entwickler weiterpflegen kann.

„Landen unsere Daten bei einem KI-Anbieter?"

Die Agenten arbeiten am Quellcode, nicht mit Ihren Produktivdaten. Welche KI-Anbieter beim Entwickeln zum Einsatz kommen, legen wir vorher gemeinsam mit Ihnen fest.

„Was, wenn Sie ausfallen?"

Wir arbeiten mit einem Netzwerk vertrauenswürdiger Kollegen zusammen, das im Notfall einspringen kann. Der Code ist dokumentiert, liegt in Ihrem Git und nutzt Standard-Technologien — jeder qualifizierte Entwickler kann nahtlos weitermachen.
